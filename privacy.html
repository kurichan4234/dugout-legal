プライバシーポリシー利用規約サポート

制定日：2026年9月26日　改定日：2026年10月22日

DUGOUT運営事務局（以下「運営」）は、草野球チーム向けアプリ「DUGOUT」（以下「本アプリ」）における利用者の情報の取り扱いについて、以下のとおり定めます。

1. 取得する情報

アカウント本アプリが自動で発行する利用者ID。Apple ID でサインインした場合は、Apple から提供される利用者ごとの識別子。
本アプリは Apple ID の氏名・メールアドレスを要求しません。
チームの情報利用者が入力したチーム名・チームカラー・軟式／硬式・活動地域、メンバーの名前・背番号・守備位置、予定（日時・対戦相手・場所・メモ）、出欠の回答、スコアブックの記録（打席結果・得点など）
募集・応募対戦相手・助っ人の募集内容（日時・都道府県・場所・レベル・メッセージなど）、応募時の名前・守備位置・メッセージ、募集側からの返信、募集したチームと応募した人のあいだのメッセージ、チームどうしの練習試合の打診（日時・場所・ひとこと・返事）とメッセージ
大会大会名・地域、参加チーム名、試合の組み合わせ・日時・会場、出場確認（確認した人の名前と日時）、結果、大会の運営スタッフの名前、大会のお知らせ・連絡
大会の参加チームの連絡先大会の事務局が登録する、参加チームの代表者・副代表の名前・電話番号・メールアドレス・メモ
大会運営ページのアカウントWeb の大会運営ページに登録したメールアドレスとパスワード（パスワードは暗号化して保存し、運営も見ることはできません）
通知プッシュ通知を届けるための端末の通知用トークン、送った通知の内容（30日で削除）
チーム登録の申請新しいチームを登録するときに運営へ送る、チーム名・軟式／硬式・活動地域・申請した人の名前・チームの紹介文
通報・ブロック通報の対象・理由・内容、ブロックしたチームや利用者
端末内の情報表示を速くするためのデータの一時保存、利用規約への同意状況、選んだ都道府県などの設定。これらは端末内にのみ保存されます。

本アプリは、位置情報、連絡先、写真、端末の広告識別子（IDFA）を取得しません。

「調整さんから出欠を取り込む」を使うと、入力された調整さんのイベントの公開されている出欠表（CSV）を読み込み、DUGOUTの出欠に反映します。調整さんへ書き込むことはありません。調整さんのURLと名前の対応は、端末の中にだけ保存します。

スコアブックの「声で記録」を使うと、マイクの音声から「ボール」「ストライク」などの言葉を聞き取ります。聞き取りは端末の中だけで行い、音声や聞き取った文字を保存したり、運営やほかのサービスに送ったりすることはありません。記録されるのは、聞き取った判定（ボール・ストライクなど）だけです。

2. 利用目的

  1. チームの予定・出欠・スコア・成績を、チームのメンバー間で共有するため
  2. 対戦相手・助っ人の募集と応募を仲介するため
  3. 大会の運営（日程の共有、出場確認による無断欠席の防止、結果の公開、運営とチームの連絡）のため
  4. 大会の日程・出場確認・連絡、募集への応募・メッセージなどをプッシュ通知でお知らせするため
  5. 新しいチームの登録を確認し、安心して使える利用者どうしで募集・応募ができるようにするため
  6. 機種変更や再インストールの際に、同じアカウントで利用を続けられるようにするため
  7. 不適切な投稿や迷惑行為への対応（通報の確認、投稿の削除、利用停止）のため
  8. 不具合の調査とサービスの改善のため

3. 情報が見える範囲

チームの情報そのチームのメンバーだけが見られます。
募集本アプリの利用者であれば誰でも見られます（チーム名・チームカラーを含みます）。
チーム一覧管理者が「チーム一覧に載せる」を選んだチームだけ、チーム名・チームカラー・軟式／硬式・活動地域・紹介・メンバー数が本アプリの利用者に表示されます。メンバーの名前は表示されません。
大会大会の運営スタッフと、参加チームのメンバーが見られます。チーム名・試合の日程・会場・結果は、大会の公開ページで誰でも見られます（連絡先は表示しません）。
大会の参加チームの連絡先その大会の運営スタッフだけが見られます。
練習試合の打診打診したチームと打診されたチームのメンバーだけが見られます。
応募・メッセージ応募した本人と、募集したチームのメンバーだけが見られます。
チーム登録の申請申請した本人と運営だけが見られます。運営は、不適切な利用への対応のため、登録されているチームの名前・軟式／硬式・活動地域・管理者の名前とサインイン方法（Apple ID かどうか）を確認することがあります。
通報通報した本人と運営だけが見られます。通報された側に、通報者が誰かは知らされません。

募集・応募・返信・メッセージには、電話番号・メールアドレス・住所などの個人情報を書き込まないでください。本アプリは電話番号やメールアドレスと思われる書き込みを受け付けない仕組みを備えていますが、すべてを防げるものではありません。

4. 第三者への提供と外部サービス

運営は、法令に基づく場合を除き、利用者の同意なく情報を第三者に提供しません。本アプリは次の外部サービスを利用しています。

Supabaseデータの保存とサインインの仕組み（保存先：アマゾン ウェブ サービスの東京リージョン）
Apple「Appleでサインイン」、プッシュ通知（Apple Push Notification service）
GitHub Pagesこのページ、大会運営ページ・大会の公開ページの配信
調整さん出欠表の読み込み（利用者が URL を入れたときだけ。書き込みはしません）

本アプリは広告を表示せず、利用状況を分析するツールや、他社のアプリ・サイトをまたいで利用者を追跡する仕組み（トラッキング）を使用しません。

5. 保存期間と削除

  • 情報は、アカウントが削除されるまで保存します。
  • アプリ内の「チーム」→「アカウント」→「アカウントを削除」から、いつでもアカウントを削除できます。削除すると、アカウント、応募・通報・ブロックの記録が削除されます。
  • ほかのメンバーの記録を守るため、チームの予定や出欠・スコアに残っているあなたの名前は「退会したメンバー」として残ります。これらの削除を希望する場合は、チームの管理者に依頼するか、運営にお問い合わせください。
  • あなたしか参加していないチームは、アカウントの削除と同時に削除されます。
  • 規約違反への対応のため、運営は通報の記録を必要な期間保存することがあります。

6. 安全管理

通信は暗号化（HTTPS）して行い、データベースでは利用者ごとに見られる範囲を制限する仕組み（行レベルセキュリティ）を設定しています。

7. 13歳未満の方の利用

13歳未満の方が本アプリを利用する場合は、保護者の同意を得たうえで利用してください。

8. 本ポリシーの変更

本ポリシーは必要に応じて変更することがあります。重要な変更がある場合は、アプリ内またはこのページでお知らせします。
